Integration Architecture

Odoo ERP Connection
Protocol: XML-RPC (xmlrpc/2/object)
Models: account.move, account.move.line, res.partner, account.tax
Auth: API key or password-based
File: odoo_connector.py
GST Portal Input
Source: GSTR-2B download (JSON or Excel)
Parser: Supports both formats automatically
Fields: Supplier GSTIN, Invoice, Taxable, Tax, Filing Status
Output Files
1. GST_Compliance_Report_v2.xlsx — 18-sheet workbook
2. GSTR1_Upload_Ready.json — Portal upload format
3. dashboard_data.json — Dashboard feed
4. odoo_connector.py — Odoo API module
